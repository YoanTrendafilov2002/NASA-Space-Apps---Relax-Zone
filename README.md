## Try the Umm Al Quwain case

Open the [Umm Al Quwain study area](https://sartainty-free.rws-cloudflare-host.workers.dev/?site=uae-coastal-review) and select **Acquisitions**. Compare **9 October** and **21 October 2026** in **HH**, then ask the Assistant, “What does this HH time series show?”

The median radar return inside the same reference outline was **2.22 dB weaker** on 21 October. The red outline comes from a separate Sentinel-1 interpretation. The 2 November point is shown separately because its NISAR product uses a newer processing release.
